# Suraksha Yatra

### Road Incident Reporting and Travel Safety Application

## About the Project

Suraksha Yatra is a mobile application designed to help people in Nepal report road problems and check road conditions before traveling.

The main idea of this project is to make it easier for travelers to share information about landslides, floods, damaged roads, and road blockages. Users will be able to report incidents and view information shared by others on a map.

The application will also help travelers check reported road problems along their selected journey.

## Planned Features

- User registration and login
- Report road incidents with photos and locations
- View reported incidents on a map
- Verify reports through authorized users
- Add updates to existing incidents
- Check incident status (Active, Partially Cleared, Resolved)
- Check road incidents along a selected route
- AI-assisted travel information

## Technologies

- **Flutter and Dart:** Mobile application
- **Node.js and Express.js:** Backend API
- **MongoDB:** Database
- **React:** Admin dashboard
- **MVVM:** Mobile application design pattern

## Project Goal

The main goal of Suraksha Yatra is to make road incident information easier to find and share. It aims to help travelers learn about possible road problems before starting their journey.

## Project Status

The project is currently in the planning and design stage. Development will be carried out as part of the Mobile Application Development module at Softwarica College of IT and E-Commerce, affiliated with Coventry University.
